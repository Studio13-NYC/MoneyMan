# MoneyMan

A small Windows desktop app that monitors your **OpenAI** and **Cursor** spend for the current month, runs in the system tray, and sends smart desktop notifications when spend changes. An LLM summarizes changes so notifications are concise and informative.

## How to run

**From source (development)**  
In the project folder:
```bash
npm install
npm start
```
The app window opens and the icon appears in the system tray. Close the window to hide it; use the tray icon to show it again. Quit from the tray menu (right-click → Quit).

**Portable exe**  
Build a single runnable exe (no installer):
```bash
npm install
npm run generate-tray-icon
npm run build
```
Run **`dist\MoneyMan 1.0.0.exe`**. Put a `.env` file in the same folder as the exe (or in `%APPDATA%\MoneyMan\`) with `OPENAI_API_KEY` and optional `CURSOR_API_KEY`. To have it in Start search: right-click the exe → **Pin to Start**, or create a shortcut in `%APPDATA%\Microsoft\Windows\Start Menu\Programs`.

## Features

- **System tray** – Runs in the background; click the tray icon to show or hide the window.
- **Desktop notifications** – Only when spend *changes* from the last saved snapshot (no spam).
- **LLM summaries** – Notifications are generated by an LLM so they're short and contextual.
- **Configurable polling** – Default: every 15 minutes; change it in the app (5–1440 minutes).
- **Persistence** – Saves a snapshot only when the current totals differ from the previous run.

## Setup

1. **Credentials** – Ensure your `.env` contains (project root when developing; same folder as exe or `%APPDATA%\MoneyMan\` when using the portable exe):
   - `OPENAI_API_KEY` – Used for the Usage/Costs API and for the notification LLM. Must be an [organization admin key](https://platform.openai.com/settings/organization/admin-keys) to read costs.
   - `OPENAI_ADMIN_KEY` – Optional. Used only by the "create new admin key" script. If unset, that script uses `OPENAI_API_KEY`. You need an existing org owner/admin key to create new admin keys.
   - `OPENAI_MODEL_SIMPLER_TASKS` – Optional. Model for notification text (e.g. `gpt-4o-mini`). Defaults to `gpt-4o-mini` if unset.
   - `CURSOR_API_KEY` – Optional. Cursor spend is only available for **Enterprise** teams; for personal/Pro you'll see a message and can use [cursor.com/dashboard](https://cursor.com/dashboard) for usage.

2. **Run** — See [How to run](#how-to-run) above. For the portable exe, place `.env` next to the exe or in `%APPDATA%\MoneyMan\`.

**Create a new OpenAI admin key** (for costs API or for rotating keys):
```bash
node scripts/create-openai-admin-key.js "My Key Name"
# or: npm run create-admin-key -- "My Key Name"
```
Uses `OPENAI_ADMIN_KEY` or `OPENAI_API_KEY` from `.env`. Only organization owners can create admin keys. The new key is printed once; copy it and set `OPENAI_API_KEY=` in `.env` (or store it securely).

If you get *"internal service URL"* (401), the API endpoint is not available for your account. Create an admin key in the dashboard instead: [platform.openai.com/settings/organization/admin-keys](https://platform.openai.com/settings/organization/admin-keys).

## How it works

- Polls **OpenAI** [organization costs API](https://developers.openai.com/api/reference/resources/organization/subresources/audit_logs/methods/get_costs) for the current calendar month.
- Polls **Cursor** [teams/spend](https://cursor.com/docs/account/teams/admin-api) (Enterprise) for the current billing cycle.
- Compares the new totals to the last saved snapshot; if different, saves and asks the LLM for a one-line notification, then shows a Windows notification.

## Run at startup (optional)

Create a shortcut to `MoneyMan 1.0.0.exe` and place it in `%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup`.

## Tech

- **Electron** – Tray, window, notifications. Build target: Windows portable exe.
- **.env** – Dev: project root. Portable exe: same folder as the exe or `%APPDATA%\MoneyMan\`.
- **Storage** – Config and snapshot JSON in `%APPDATA%\MoneyMan\`.
